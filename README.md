# 🐘 Modern-PHP-Learning-And-Projects

My structured, self-paced learning path for mastering modern **PHP 8** fundamentals, modern Object-Oriented Programming (OOP), and practical database-driven projects. The repo contains my study notes (heavily commented) and projects that go along with those topics, ranging from simple to somewhat complex.

## 📁 Repository Structure

```text
Modern-PHP-Learning-And-Projects/
│
├── .gitignore              # Ignores vendor/, environment files (.env), and logs
├── README.md               # Project documentation and progress tracker
│
├── 01-introduction/        # PHP introduction, XAMPP + VSCode + Git setup
│   ├── notes.txt
│   └── index.php           # first php file for testing
│
│
└── xx-next-steps/
```

## 🛠️ Environment Setup

1. Place this folder inside your XAMPP local web server root (`htdocs`).
2. Start **Apache** (and **MySQL** for database projects) via your local control panel.
3. Access files in your browser at:
   `http://localhost/Modern-PHP-Learning-And-Projects/01-introduction/`
